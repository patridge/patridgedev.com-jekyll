# PatridgeDev blog, source

I've moved off WordPress to GitHub Pages, trading the constant engine, extension, and theme updates for a much smaller set of regular Jekyll dependency updates. I'll even be doing my draft posts in here too, where they will probably start in a branch before either publishing or ending up in the official drafts folder.

## Running the site locally

These steps are mostly for future-me, but feel free to run things locally to see how things are working with this set of templates and styles.

1. Install Jekyll (Requires Ruby).

    ```bash
    gem install bundler jekyll
    ```

1. Build and serve the site.

    ```bash
    bundle exec jekyll serve
    ```

1. Open the site in your favorite (or least problematic) browser.
